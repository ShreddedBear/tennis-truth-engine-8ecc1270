---
name: Approved tennis data sources
description: The required source allowlist and priority for Tennis Matrix evidence.
---

Use sources in this order for each field: existing application/database data, the Aneeshers Sackmann archival mirror, ppaulojr point-by-point data (with Sackmann Grand Slam PBP fallback), then Live Tennis API.

Do not add or depend on any other external tennis API or paid provider. Preserve Sackmann attribution and CC BY-NC-SA 4.0 requirements. Missing point-by-point or historical evidence must remain unavailable rather than being converted to zero or fabricated.

**Why:** The project deliberately limits cost and provider risk while preserving strict, source-proven evidence.

**How to apply:** Audit existing data first. Prefer reliable local reconstruction over Live Tennis API calls, and use Live Tennis only for current data or fields unavailable from approved archival sources.
