But the 4,929 ≠ 4,929 gradeable matches

The report correctly identifies the real blocker:

1,117 of 3,266 players cannot currently be deterministically mapped to your canonical player identities.

That affects 1,995 matches.

And even the remaining 2,687 cannot yet become the frozen holdout because the system hasn’t proven that the features used by the Prediction Engine are genuinely historical.

That’s the much more important issue.

For example, this would be leakage:

Match: Player A vs Player B
Match date: September 5
Prediction generated using:
Player A's current ranking
Player A's September 20 statistics
Player B's current Elo
Player B's complete 2026 season record

Even though the match itself occurred September 5, those values weren’t necessarily available on September 5.

That would make the backtest invalid.

If 4,929 matches exist but only 2,100 can genuinely satisfy all point-in-time requirements, then the honest result is a 2,100-match evaluation—not an artificially completed 4,929-match evaluation.

The Truth Engine should have an independent gate

I would keep the Truth Engine separate from the Prediction Engine eligibility decision.

A match could theoretically be:

Prediction eligible
→ enough historical pre-match features exist.

But:

Truth Engine partially verified
→ winner verified, but some audit evidence unavailable.

That should not be converted into fake “fully verified” status.

The Truth Engine should report the actual evidence state.

So the final record might legitimately say:

Prediction:
  GENERATED
  CORRECT
Truth Engine:
  AUDIT COMPLETED
  WINNER VERIFIED
  PBP: GENUINELY_UNAVAILABLE
  INJURY: GENUINELY_UNAVAILABLE
  WEATHER: VERIFIED
  IDENTITY: VERIFIED

That’s vastly more valuable than making every field green.
