# DataHub ATP World Tour tennis data

Source: https://datahub.io/core/atp-world-tour-tennis-data
Upstream project: https://github.com/serve-and-volley/atp-world-tour-tennis-data
License: Creative Commons Attribution 4.0 International (CC BY 4.0), as stated by DataHub.

Included here:
- ATP match scores 1991-2017
- ATP detailed match statistics 1991-2017

Supported raw fields include aces, double faults, first serves, first/second serve points won, break points saved/faced, service points, return points, return-game totals, service-game totals, and total points.

IMPORTANT LIMIT: this source ends in 2017. It may be used only as genuinely historical evidence. It must not be represented as current 2026 serve/return form, and it must not fill a metric when the audited player has no supported pre-match observations in these files.
