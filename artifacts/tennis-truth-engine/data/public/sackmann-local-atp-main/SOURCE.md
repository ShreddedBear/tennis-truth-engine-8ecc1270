# Sackmann Local ATP Main Source

## Provenance

These files were copied from Jeff Sackmann's `tennis_atp` dataset through the sibling [Tennis-Stats-Engine](https://github.com/ShreddedBear/tennis-stats-engine) repository at `attached_assets/sackmann_local/`. That repository received the files as an uploaded ZIP represented as a byte-identical copy of Jeff Sackmann's data. No `LICENSE` file accompanies this dataset in either location.

## Coverage and data type

The files present cover ATP Main matches from 2012 through 2023. They contain **MATCH_STATS** data: match-level serve and return statistics. They are not point-by-point data.
