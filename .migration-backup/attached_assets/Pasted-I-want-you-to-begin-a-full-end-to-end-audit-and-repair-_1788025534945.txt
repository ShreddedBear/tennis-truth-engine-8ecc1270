6. VERIFY PREDICTION SNAPSHOTS

Audit the immutable prediction snapshot system.

When a prediction is generated, verify that the metric values actually used by the model are saved with that prediction.

Later database changes must NOT silently rewrite the historical prediction’s original evidence.

Confirm that Prediction History, Shadow Replay, Walk-Forward, and Backtesting are using the correct historical snapshot/context rather than today’s recalculated values where that would create leakage.

7. VERIFY FRONTEND WIRING

For every metric displayed in the UI:

* Identify the exact API/database source.
* Confirm it is the same value used by the prediction engine when appropriate.
* Confirm formatting isn’t changing the underlying value.
* Confirm percentages aren’t being converted incorrectly.
* Confirm decimal values aren’t being treated as percentages.
* Confirm confidence isn’t being confused with probability.
* Confirm Monte Carlo probability displays the predicted winner’s actual simulated win probability.
* Confirm missing data is clearly represented.

No frontend metric should be independently re-calculating a value that should come from the backend unless that behavior is explicitly intended.
